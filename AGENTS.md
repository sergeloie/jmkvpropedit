# AGENTS.md — Инструкции для кодинг-агента

Этот файл — точка входа для любого агента, работающего в этом репозитории.
Прочитай его первым. Он отвечает на вопрос "базовые правила работы с репозиторием".

> Принцип: AGENTS.md — это **навигация и правила взаимодействия**, а не стайлгайд.
> Никаких "используй `var` вместо `val`", "ставь скобки так". Только то, что влияет на архитектуру и эффективность работы агента.

## 1. Карта каталогов

| Путь | Назначение | Коммитится? | Кто читает |
|------|------------|-------------|------------|
| `docs/` | **Документация для человека.** Архитектура, API. | Да | Человек |
| `docs/agents/` | **Постоянная документация для агента.** Глоссарий (`context.md`), конвенции (`conventions.md`), ADR (`adr/`). | Да | Агент + Человек |
| `plans/` | **Временная документация для агента.** Планы, исследования, черновики PRD. После мерджа — удаляется. | Нет | Агент |
| `.tmp/` | **Утилитарный временный каталог.** JSON для curl, дампы API, логи прогонов. Агент пишет сюда что угодно. | Нет | Только агент |
| `.agents/` | **Каталог для скиллов и данных агента, специфичных для этого репозитория.** skill-observations, наблюдения за поведением операционной системы, скриптов. Агент пишет сюда техническую информацию для постоянного хранения. | Нет | Только агент |


**Правило выбора места:**
- Увидит ли человек через полгода? → `docs/`
- Нужно ли следующему агенту через месяц? → `docs/agents/`
- Нужно только на время задачи? → `plans/`
- Мусор для отладки? → `.tmp/`
- Нужно аккумулировать опыт о работе инструментов, поведении кода, скриптов, технических нюансах окружения? → `.agents/`

Issues live in GitHub Issues (via `gh` CLI). See `docs/agents/issue-tracker.md`.

Default five-role vocabulary: `needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`. See `docs/agents/triage-labels.md`.

Single-context: root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
